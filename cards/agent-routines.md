## Steps

### General

Your AI agent enforces morning routines with a gate-and-streak system.
- On a trigger event (e.g., first interaction of the day), the agent presents a checklist: push-ups, plank, dead hang, squats, meditation sit. Each item must be confirmed before moving to the next.
- The agent gates a desired deliverable (e.g., morning briefing) behind checklist completion — you don't get your news until you've done your routine. This is environmental design, not willpower.
- Streaks are tracked over time. The agent surfaces streak data and adjusts ramp schedules (e.g., add one rep per week).
- Trade-off: Requires a running agent with a messaging interface (Telegram). The enforcement is software-based — you can lie to the agent, but you're only cheating yourself. The value is in the ritual, not the coercion.
- Why this is different from a habit app: The agent is conversational — it can negotiate, ask how you're feeling, adjust the routine if you're injured, and connect routine completion to other systems (e.g., only deliver your briefing after you're done).
