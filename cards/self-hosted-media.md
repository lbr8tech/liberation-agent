## Steps

### General

Jellyfin app on all platforms (F-Droid/Play Store for Android, App Store for iOS, web UI or desktop client for desktop). Optionally add *arr stack (Sonarr, Radarr, Lidarr) for automated media management.

## Self-Hosted

Jellyfin (FOSS, full media server, movies/TV/music)

Alternatives: Emby (partially closed source), TomSparkBox (one-command installer that bundles Jellyfin + full *arr stack + VPN — tomsparkbox.com. Closed-source integration layer over open-source apps. Untested by lbr8 — we know it exists, not that it works.)
