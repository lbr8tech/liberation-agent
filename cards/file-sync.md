## Steps

### Android

Syncthing (F-Droid) or Nextcloud (Play Store/F-Droid).

### iOS

Nextcloud (App Store). Syncthing has no iOS app.

### Desktop

Syncthing or Nextcloud desktop client.

## Self-Hosted

Syncthing (P2P sync, FOSS, no central server) or Nextcloud (full cloud replacement, web UI, more features)

Alternatives: Seafile (enterprise-grade sync), TomSparkBox (one-command installer that bundles Nextcloud + Syncthing + 40+ other apps — tomsparkbox.com. Closed-source integration layer over open-source apps. Untested by lbr8.)

## Guides

1. syncthing.net (Syncthing: P2P file sync, FOSS, no central server)
2. nextcloud.com (Nextcloud: self-hosted cloud platform with file sync, calendar, contacts, and more)
3. eylenburg.github.io/cloud_comparison.htm (Eylenburg: cloud, sync & email services comparison — 42 providers with sync, encryption, and self-hosting analysis)

## Prerequisites

Server access + backup strategy before syncing sensitive files.
