## Steps

### General

Navidrome web UI or any Subsonic-compatible client. Android: DSub, Symfonium, Tempus (scrobbling). iOS: Substreamer. Desktop: any Subsonic desktop client or Navidrome web UI.

## Self-Hosted

Navidrome (self-hosted music streaming, Subsonic API) + Tempus (scrobbling)

Alternatives: Jellyfin (media server with music support)
